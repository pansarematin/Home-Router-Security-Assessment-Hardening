# Home-Router-Security-Assessment-Hardening
🔐 Project Name: Home Router Security Assessment & Hardening

Recently, I performed a hands-on security assessment on my personal WiFi router to understand real-world network exposure and strengthen my practical cybersecurity skills.

🔍 What I did:
- Conducted port scanning using Nmap  
- Identified open ports: 80, 53, 23, 1900  
- Accessed web interface via port 80 (admin panel)  
- Explored services running on:
  - Port 23 (Telnet)  
  - Port 53 (DNS)  
  - Port 1900 (UPnP / SSDP)  

🧪 Key Learnings:
- Understood how different network services operate in real environments  
- Learned how unsecured services like Telnet can pose security risks  
- Explored device discovery protocols like UPnP  

🔐 Security Actions Taken:
- Updated router credentials with strong passwords  
- Reviewed exposed services and configurations  
- Strengthened overall router security posture  

🚀 Tools Used:
- Nmap  
- Telnet client  
- Basic networking commands  

💡 This project helped me bridge the gap between theoretical networking concepts and real-world implementation.
